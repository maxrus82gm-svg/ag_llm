## DOCUMENTATION / OBSIDIAN — ПРАВИЛА ВЕДЕНИЯ ПРОЕКТА

Документация проекта ведётся в Markdown в папке:

Документация/

и используется через Obsidian.

Документация является рабочей частью проекта и должна поддерживаться
в синхронизации с фактическим состоянием кода.

### Источник истины

При расхождении между документацией и фактическим кодом:

ФАКТИЧЕСКИЙ КОД И ФИЗИЧЕСКИ ПРОВЕРЕННОЕ ПОВЕДЕНИЕ
имеют приоритет над устаревшим текстом документации.

Перед изменением статусов, архитектуры или описания возможностей
необходимо сначала проверить актуальные файлы реализации.

Нельзя объявлять функцию:
- реализованной;
- проверенной;
- отсутствующей;

только на основании старого Markdown.
