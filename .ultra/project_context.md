# PROJECT CONTEXT — ag_llm

Проект: GigaChat Ultra Local Agent / ag_llm.

Это локальная система для работы LLM как управляемого файлового и проектного агента.

PROJECT CONTEXT содержит только постоянные правила Workspace.
Подробная архитектура и инструкции находятся в документации проекта.
Документы, которые нужно прочитать для конкретной задачи, должны быть явно указаны в самой TASK.

ОСНОВНЫЕ ПРАВИЛА

- Выполняй только текущую TASK и не расширяй её область самостоятельно.
- Не изменяй файлы, которые не относятся к TASK.
- Не удаляй файлы, если удаление прямо не требуется задачей.
- Если TASK ограничивает работу конкретными файлами или каталогами — строго соблюдай это ограничение.
- Перед изменением существующего файла сначала ознакомься с его актуальным содержимым или нужным фрагментом.
- Для небольших изменений предпочитай точечное редактирование полной перезаписи файла.
- Не уничтожай существующий рабочий код, данные или структуру файла без прямого требования TASK.
- После изменения проверь фактический результат и перечитай изменённый участок или файл.
- Не объявляй действие выполненным только на основании собственного текста или старого REPORT — опирайся на фактический результат инструментов.
- Если текущее состояние файлов расходится с документацией, не исправляй это самовольно: учитывай фактическое состояние и требования текущей TASK.
- Не придумывай отсутствующие требования, архитектурные решения или содержимое файлов.
- Используй только разрешённые сервером инструменты, permissions и scopes; не пытайся обходить ограничения.
- Не изменяй служебное persistent-состояние `.ultra` напрямую, если это явно не является частью TASK.
- Читай только документацию, явно указанную в TASK, либо минимально необходимый файл для устранения конкретного блокера. Не загружай документацию проекта целиком без необходимости.

Все специфические требования:
- какие документы прочитать;
- какие файлы разрешено менять;
- что именно реализовать;
- что сохранить;
- какие проверки выполнить;

должны приходить в текущей TASK.
