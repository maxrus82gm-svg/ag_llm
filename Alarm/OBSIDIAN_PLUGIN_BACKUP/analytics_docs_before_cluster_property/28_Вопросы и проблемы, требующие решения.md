# Вопросы и проблемы, требующие решения

**Назначение:** входная точка для архитектурного обсуждения вопросов, которые возникают из текущего состояния проекта, но ещё не являются принятым решением.

Связь с фактической архитектурой: [[01_Архитектура и текущее состояние]]

Этот документ фиксирует:
- конкретную проблему или вопрос;
- почему он возник;
- какие части текущей архитектуры затронуты;
- ограничения и условия;
- что именно требуется выяснить;
- какие материалы должны анализировать независимые стороны.

## Правило
Запись в этом документе **не меняет** `01` и не означает, что решение принято.

Для каждого вопроса использовать отдельный ID: `Q-001`, `Q-002`, ...

После постановки вопрос передаётся независимо в:
- [[29_Независимая аналитика Claude]]
- [[30_Независимая аналитика GPT]]

Следующий этап после независимых разборов: `31_Общая идея и согласованное решение.md`.
