# Независимая аналитика GPT

**Назначение:** хранить независимый разбор GPT по вопросам из [[28_Вопросы и проблемы, требующие решения]].

Источник фактического состояния проекта: `01_Архитектура и текущее состояние.md`.

GPT должен анализировать вопрос самостоятельно и не подстраивать вывод под Claude или заранее ожидаемое решение.

Для каждой записи указывать:
- ID вопроса из `28`;
- модель / режим, если важно;
- кратко изученные материалы;
- собственные выводы;
- найденные риски и противоречия;
- альтернативы;
- рекомендуемое направление;
- уровень уверенности / что осталось проверить.

Этот документ **не является канонической архитектурой** и сам по себе ничего не разрешает менять.

После готовности анализа его выводы сопоставляются с Claude в [[31_Общая идея и согласованное решение]].
