# ALARM TASK SESSION — инструкция удалённой работы

Эта зона используется при работе ChatGPT с проектом через удалённый доступ к компьютеру (Desktop Commander Remote / эквивалентный канал).

## Обязательное правило входа
1. Определить номер текущей TASK.
2. Открыть `Alarm/ALARM_TASK_SESSION/TASK_<N>/`; если папки нет — создать её.
3. Перед продолжением прочитать `context.md`, `history.md` и последние записи `session.jsonl`.
4. Если последний шаг имеет `INTENT` без подтверждённого `DONE` / `VERIFIED`, сначала проверить фактическое состояние на диске и только потом решать, повторять ли действие.

## Правило каждой изменяющей операции
- Сначала записать в `session.jsonl`: `INTENT` — что именно планируется сделать и с каким объектом.
- Затем выполнить действие.
- После фактического выполнения записать `DONE`.
- После независимой проверки результата записать `VERIFIED`.
- Если действие не выполнилось или связь оборвалась до подтверждения, не придумывать `DONE`: незакрытый `INTENT` остаётся точкой аварийного восстановления.

## Файлы TASK-сессии
- `session.jsonl` — оперативный журнал шагов и состояний.
- `context.md` — краткое текущее состояние: цель, текущий этап, следующий безопасный шаг, риски.
- `history.md` — человеческая хронология значимых действий, решений, проверок и обрывов.

Чтения без изменения данных можно выполнять без отдельного INTENT. Любые write/edit/delete/move и другие изменяющие действия должны проходить через журнал.
