# Постоянные файлы запуска Студии Нейрополис

| Файл | Режим |
| --- | --- |
| `Start_WebAlarm_Standard.cmd` | Штатный запуск со своими Workspace, чатами и настройками. |
| `Start_WebAlarm_Test.cmd` | Изолированный TEST. Ответы синтетические, данные временные. |

Откройте нужный файл двойным щелчком. Оба файла используют Python из `.venv` и открывают локальный интерфейс в браузере. TEST использует `web_alarm/launch_test_config.json` и останавливается, если профиль отсутствует или повреждён. Чтобы завершить приложение, используйте команду «Завершить Студию Нейрополис» в STANDARD или нажмите Enter в консоли TEST.

## GigaChat в STANDARD

1. Настройте существующие переменные `GIGACHAT_CREDENTIALS` и `GIGACHAT_SCOPE` с профилем `GIGACHAT_API_PERS`.
2. В EVM включите нужную модель. Нажмите «Подключить GigaChat» и подтвердите разрешение на использование API. Подключение проверяет каталог аккаунта.
3. Откройте Чат Нейрополис, выберите модель и отправьте сообщение. Генерация может тарифицироваться. «Проверить чат» остаётся отдельной диагностикой с подтверждением.

При обычном запуске и обновлении страницы Студия читает локальное состояние. Первая явная отправка восстанавливает техническую сессию при действующем разрешении и проверяет каталог. Отправленные сообщения остаются в истории. При неопределённом исходе используйте «Проверить состояние запроса».

«Отключить GigaChat» в EVM отзывает разрешение. При смене ключа, профиля или условий допуска подтвердите его заново. Выключатель на карточке управляет отправкой к отдельной модели. Черновики, история и настройки доступны при отключённом провайдере.

Разрешение владельца сохраняется при штатном завершении. Срок внутреннего технического допуска — 24 часа, не срок согласия; при следующей явной отправке Студия восстанавливает сессию автоматически, если разрешение и реквизиты действительны. Возраст проверки и открытие страницы не инициируют платную генерацию.

В EVM общая шкала для всех моделей настраивается справа под управлением GigaChat. По умолчанию: зелёный — успешный ответ менее 20 дней назад; жёлтый — 20–26; оранжевый — 27–29; красные часы — 30 дней и более; красный крест — подтверждённая ошибка; серый — модель выключена; неизвестный статус — подтверждения нет или исход неизвестен. Пороги можно сохранять и сбрасывать, они информационные и сами не блокируют отправку. Дата рядом с моделью относится к последнему успешному ответу именно этой модели, дата в списке чатов — к последнему сохранённому сообщению. Сохранённое подтверждение не становится оранжевым только из-за перезапуска при действующем согласии.

## Локальные LLM — подключение Client (READ_ONLY)

Интерфейс #679: scoped Windows CI на объединённом 0e7adfb прошёл (run 45804549718). 29.11.2026 владелец выполнил штатное подключение HOME Client №173 к Studio: проверка Bridge успешна, каталог появился (OWNER GUI BOUNDED PASS; M1-10 PARTIAL, не проверка каждой модели и не разрешение генерации). [Запись WEB37](reports/CHATGPT-WUA-COLIBRI-M1-10-READINESS-20261124-001/owner_gui_20261129.md). Для новых машин — согласованный профиль и разрешение владельца. Обычное подключение через EVM без редактирования кода, CMD или CLI. [Сценарий M1-10/M1-11](reports/CHATGPT-WEB36-H47-REVIEW-20261126/live_preflight.md).

1. Откройте Клиент Нейрополис (№173 или совместимая версия); после обновления страницы F5 выберите слева «Подключение к Студии». Нажмите «Включить Bridge», затем «Проверить подключение» и дождитесь успешного статуса. Если проверка неуспешна, не переходите к подключению. Перезапуск Client, остановка Manager и моделей не требуются.
2. В штатном STANDARD Студии откройте EVM → «Локальные LLM» → «Клиент Нейрополис». В Client нажмите «Копировать путь», вставьте его в поле защищённого профиля Studio (или выберите тот же профиль через «Обзор…»); затем «Копировать ID» и вставьте Bridge ID в соответствующее поле. Не копируйте и не вводите токен. Не передавайте путь/ID посторонним. Если на другой машине нужно сначала подключить Manager к Client, не обходите защиту и не редактируйте исходники: отдельная инструкция по первичному подключению Manager запланирована, пока не подтверждена.
3. Нажмите «Подключить» и подтвердите действие. Studio проверяет защищённую discovery и только GET health/models, затем показывает Manager/слот/статус всех моделей.
4. «Обновить каталог» получает новые модели и состояния. F5 сохраняет текущую проекцию; после полного перезапуска привязка восстанавливается без сетевого запроса — нажмите «Обновить каталог». Если origin/launch_identity изменился, подтвердите профиль и Bridge ID заново кнопкой «Подключить».
5. «Отключить» удаляет только привязку Studio и её текущий каталог. Client, Manager, модели, история и настройки остаются на месте. При обрыве после обновления известные модели становятся UNKNOWN. READY не доказывает idle или готовность генерации. Генерация и управление моделями закрыты. Первый настоящий локальный ответ требует отдельной реализации допуска STANDARD и отдельного M1-11 GO; не обходить READ_ONLY и тестовый транспорт.
6. Если профиль, ACL, идентичность или хранилище не подтверждены, подключение не заменяется молча. При повреждённой привязке или конфликте экземпляров сначала диагностировать файл метаданных, не сбрасывать его без проверки.

Диагностические параметры H46 остаются отдельным режимом без ручного блока: [отчёт H46](reports/CODEX-WUA-COLIBRI-REAL-CATALOG-001/report.md). TEST не получает управление Client. Никаких реальных обращений до отдельного OWNER GO.
