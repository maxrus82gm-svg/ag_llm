# Реестр задач Blueprint LLM

**Назначение:** полные поручения, их уточнения и фактические результаты по направлению Blueprint. **Индекс:** `43.1_ID задач Blueprint LLM.md`. **План:** `43_План работ по Blueprint LLM.md`.

**Порядок чтения:** сначала индекс, затем одна запись по ID. Полную историю при обычном входе не загружать. Каждая запись ограничена парой маркеров `TASK-RECORD <ID> BEGIN` и `TASK-RECORD <ID> END`. >
> - Исполнитель: какую LLM использовать и на каком сервере она находится.
> - Роль: планировщик, исполнитель, проверяющий, собеседник и так далее.
> - Вход: задача пользователя, контекст, результаты других LLM, код, файлы или структурированные данные.

>
> Настройки экземпляра

> Роль: Планировщик
>
> Подключение: выбранный сервер
>
> Входящие пины
>
> ○ Задача
>
> ○ Контекст
>
> ○ Ответ другой LLM
>
> ○ Данные / код

>
