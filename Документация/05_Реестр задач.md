- [x] История выбранного Chat хранится как persistent multi-turn RAW / SUMMARY Working Representation

### TASK 06.4 — Разделение контекстов
- [x] Raw history неизменна

- [ ] Автоматический context-budget manager, RELEVANT PRIOR FACTS и предупреждение при trimming — будущая отдельная работа

### TASK 06.5 — Сжатие контекста
- [x] Per-message LLM compression создаёт Proposal от immutable RAW
- [x] Один отдельный Compressor call, soft guard и не более одного corrective retry
- [x] Ручная правка, Accept / Reject, Original Viewer, Restore и повторное сжатие
- [x] Active SUMMARY сохраняется как Working Representation и доступен context policy; TASK 139 не включает старые Chat messages в Executor автоматически
- [x] Модель сжатия берётся через COMPRESSION MODEL ASSIGNMENT
- [ ] Compression Review / Discussion Chat
- [ ] Отдельные VERIFY и FINALIZE model calls в целевом COMPRESS → VERIFY → FINALIZE
