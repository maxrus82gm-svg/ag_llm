## Критерии приёмки для ближайших задач

### TASK 06.1 — Модель данных чатов
- [x] Создана структура директорий для чатов
- [x] История сохраняется на диск
- [x] Метаданные хранятся в JSON
- [x] API для create/list/persistence/rename чатов реализован
- [x] Проверка: чаты сохраняются после перезапуска

### TASK 06.2 — Навигация по чатам
- [x] Sidebar со списком чатов
- [x] Создание нового чата
- [x] Переключение между чатами
- [x] Изоляция контекстов
- [ ] Удаление чата — НЕ РЕАЛИЗОВАНО
- [x] Переименование чата

### TASK 06.3 — Multi-turn context
- [x] Модель получает историю выбранного Chat через активную RAW / SUMMARY Working Representation
- [x] Устранено расхождение UI/API
- [x] Несколько user/assistant сообщений попадают в Active Chat Context в активном представлении

### TASK 06.4 — Разделение контекстов
- [x] Raw history неизменна
- [x] Active context использует сохранённую RAW / SUMMARY Working Representation
- [ ] Автоматический context-budget manager и предупреждение при trimming — будущая отдельная работа

### TASK 06.5 — Сжатие контекста
- [x] Per-message LLM compression создаёт Proposal от immutable RAW
- [x] Один отдельный Compressor call, soft guard и не более одного corrective retry
- [x] Ручная правка, Accept / Reject, Original Viewer, Restore и повторное сжатие
- [x] Active SUMMARY сохраняется и используется Main Chat после подтверждения
- [x] Модель сжатия берётся через COMPRESSION MODEL ASSIGNMENT
- [ ] Compression Review / Discussion Chat
- [ ] Отдельные VERIFY и FINALIZE model calls в целевом COMPRESS → VERIFY → FINALIZE

### Ветка V: Execution Verifier
- [x] V.1–V.5: Model Assignment, clean runtime, Final Audit и bounded same-RUN correction
- [x] Permission capability escalation: реализовано в коде и покрыто tests; live пользовательский RUN не подтверждён
- [ ] V.6: Task Contract — следующий этап
- [ ] PREFLIGHT / MUTATION gates и автоматический Execution Consistency — будущие этапы; mutation intent trace сейчас diagnostic-only
