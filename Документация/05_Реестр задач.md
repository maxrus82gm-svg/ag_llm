## Критерии приёмки для ближайших задач

### TASK 06.1 — Модель данных чатов
- [ ] Создана структура директорий для чатов
- [ ] История сохраняется на диск
- [ ] Метаданные хранятся в JSON
- [ ] API для CRUD чатов реализован
- [ ] Проверка: чаты сохраняются после перезапуска

### TASK 06.2 — Навигация по чатам
- [ ] Sidebar со списком чатов
- [ ] Создание нового чата
- [ ] Переключение между чатами
- [ ] Изоляция контекстов
- [ ] Удаление/переименование

### TASK 06.3 — Multi-turn context
- [ ] Модель получает полную историю
- [ ] Устранено расхождение UI/API
- [ ] Проверка на длинном диалоге

### TASK 06.4 — Разделение контекстов
- [ ] Механизм учёта размера
- [ ] Raw history неизменна
- [ ] Active context управляем
- [ ] Предупреждение при trimming

### TASK 06.5 — Сжатие контекста
- [ ] Интерфейс выбора фрагмента
- [ ] Генерация summary
- [ ] Сохранение оригинала
- [ ] Редактирование summary
- [ ] Действия: Сжать, Развернуть, Показать оригинал
