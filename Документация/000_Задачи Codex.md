**Обнаружен FAIL:**

1. Пользователь выбирает GigaChat Pro, Lightning или Ultra.

**Реализовать долговременное сохранение выбора LLM отдельно для каждого TEST-диалога.**

Пользователь должен иметь возможность выбрать разные модели в разных чатах и получать тот же выбор после переключения между диалогами и F5.

Никаких реальных LLM-вызовов для этого не требуется.

## 3. Требования к реализации

### P0 — исправить подтверждённый дефект

1. Исследовать существующие TEST-маршруты, метаданные чатов, модельный каталог и механизм хранения настроек.
2. Переиспользовать существующий механизм сохранения, если он подходит для изолированного TEST.
3. Сохранять выбор по устойчивой идентичности **Workspace ID + Chat ID**, а не глобально для страницы или по названию чата.
4. При открытии чата восстанавливать его собственную модель.
5. После F5 восстанавливать модель без необходимости повторного ручного выбора.
6. Смена модели в чате A не должна менять модель чата B.
7. При отсутствии сохранённого выбора разрешается начальная модель по умолчанию.
8. При повреждённой либо отсутствующей в каталоге сохранённой модели не выдавать молчаливую подмену за восстановленный выбор. Нужны безопасный fallback или явное предупреждение согласно существующему контракту.
