# Claude — технические заметки и наблюдения

**Назначение:** рабочий технический справочник по использованию Claude как второго внешнего AI-агента рядом с ChatGPT и проектом `ag_llm`.

## Что хранится в этом документе

- фактические наблюдения по моделям Claude;
- замеры Context Window, Session limit и Weekly limit;
- заметки по Claude Desktop / Claude Code;
- локальная сетевая схема доступа и эксплуатационные нюансы;
- результаты небольших сравнительных тестов;
- ссылки на официальные материалы Anthropic.

**Не хранить:** пароли, Organization ID, session tokens, API keys, cookies, платёжные данные и другие секреты.

- Подписка Claude Pro активирована.
- В Claude открыт рабочий проект `M:\GitHub\ag_llm`.
- Основная модель первого теста: **Claude Opus 5.5**.

## Модели — рабочая ориентация на 2026-10-03

- **Claude Opus 5.5** — текущая ведущая модель Anthropic для сложной работы, требующей аккуратного суждения; основной кандидат для сложного кода, агентных и длинных задач.
- Anthropic заявляет, что Opus 5.5 на большинстве задач работает примерно на уровне Claude Fable 5.1.
- **Claude Sonnet 5.5** — более быстрый и дешёвый компаньон Opus 5.5; предпочтителен для хорошо ограниченных повседневных задач, исправления багов и типовой производственной работы.
- **Claude Fable 5.1** — отдельная верхняя модель для сложного coding/knowledge work; доступность и тарифные ограничения проверяются отдельно и не выводятся только из сравнения качества.

### Как трактовать цифры

`Context Window` — объём активного контекста текущей сессии, а не прямое количество процентов тарифа.
`Session limit` — отдельный процент текущего лимита использования.
`Weekly limit` — отдельный недельный лимит.
Поэтому рост контекста и расход Session/Weekly нужно записывать раздельно.

## Сетевая схема Claude на текущем ПК

- v2rayN: TUN = OFF;
- активный routing-профиль: `ChatGPT HTTP`;
- локальный mixed HTTP/SOCKS proxy: `127.0.0.1:10808`;
- основные домены Claude / Anthropic уже направлены в proxy-правило;
- для Claude Desktop и cowork установлены fail-closed firewall rules, блокирующие прямой Internet-выход;
- приложение Claude работает и отвечает через текущую схему;
- веб-страница account/settings при этом может показывать региональную заглушку — это не означает, что сам Claude Desktop не работает.
