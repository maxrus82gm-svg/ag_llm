# Решение пользователя — ChatGPT: независимые тесты и правки кода

**Дата:** 2026-10-22. **Статус:** новое прямое пользовательское решение, требующее синхронизации действующих контрактов 18 / 36.1 и маршрута 08 / 34. Предыдущие категорические запреты от 2026-10-14/21 не отражают это решение.

## Фактическое распределение ролей

- **Основной режим:** ChatGPT — координатор, планировщик, независимый reviewer/verifier; Claude и Codex — обычные самостоятельные исполнители инженерных задач.
- **Самостоятельная проверка:** во время review ChatGPT может самостоятельно создавать и исполнять безопасные временные диагностические тесты/скрипты/probes на синтетических данных в изолированной среде и использовать доступные безопасные GitHub Actions. Для каждой такой проверки не нужно назначать отдельную задачу Claude/Codex. Реально доступные инструменты, ревизию, CI-triggers, результаты и ограничения проверять перед утверждениями.
- **Изменение кода:** по прямому поручению пользователя в конкретном чате ChatGPT вправе лично исправлять небольшие/согласованные участки программного кода, постоянные тесты, скрипты, runner или CI, а также публиковать разрешённые изменения через GitHub. Отсутствие такого поручения означает отсутствие права самовольно менять инженерные файлы репозитория. Технический write-доступ сам по себе не выдаёт согласие на произвольный fix.
- **Отдельная приёмка:** собственные тесты ChatGPT — авторская проверка его исправления, не независимый verdict по тому же исправлению. Для финального независимого принятия нужен другой проверяющий или отдельно согласованный внешний gate. GitHub Actions PASS не подменяет source-review.
- **Безопасность:** действие ограничено текущим scope, актуальным HEAD, конфликтами параллельной работы, секретами и публикационной безопасностью. Производственные/live/destructive действия и неоговорённый rollout не разрешаются. Права Git/GitHub локальных Claude/Codex не изменяются.

## Долговременное применение

Координатор обязан перенести это решение в нормативные владельцы `DOC-ENGINEERING-ROLES-01` (18) и `TEST-COLLAB-01` (36.1), затем актуализировать `08_Старт`, `34_TACTICAL_CONTEXT` и персональную карточку ChatGPT. До синхронизации **не заявлять, что старые нормативные определения уже заменены в GitHub**. Исторические отчёты и активные БЛОКИ 1–4 не переписывать.

Цель — исключить ошибочный вывод «ChatGPT никогда не может писать код или свои тесты» и одновременно сохранить пользовательский контроль над изменениями GitHub.
