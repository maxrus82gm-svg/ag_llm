## Обязательный gate LOCAL-PLAN-01

Каждый координатор через Desktop Commander на DESKTOP-SC96D3U читает этот файл под общей блокировкой при входе в чат, перед постановкой **любой новой задачи**, изменением плана, после значимого результата и перед закрытием этапа. В карточке фиксировать PLAN_READ: SHA256, время, stage либо отсутствие влияния. Без чтения задача не назначается. Полной копии плана в Colibri не создавать. Исходники обоих проектов читать GitHub-first; это узкое исключение касается общего локального плана, не меняет CI и права Git. В INDEPENDENT_PLAN gate выполняет координатор до выдачи изолированной карточки.

Только локальный helper; не редактировать файлы GitHub API, редактором, Obsidian или конкурирующими копиями. На HOME в PowerShell:

    Set-Location -LiteralPath 'M:\GitHub\ag_llm'
    python tools/shared_integration_plan.py read
    python tools/shared_integration_plan.py update --actor COLIBRI --stage P0 --expect <PLAN_SHA256> --status IN_PROGRESS --task <LOCAL_TASK_ID> --next 'Следующий шаг'

WUA использует --actor WUA. Поля update: status, task, evidence, next. Нельзя менять таблицу соседа или общие критерии односторонне; изменение roadmap/новых строк — отдельно согласованный локальный maintenance обоими под тем же lock. Нельзя подменять actor. Helper использует Windows byte-range lock .git/wua-colibri-plan.lock, SHA CAS, атомарный replace и readback; lock освобождает ОС при завершении процесса. Не удалять lock-файл. PLAN_BUSY / STALE_PLAN: перечитать, согласовать, повторить. Недоступность компьютера/файла/lock — STOP, сообщить владельцу, никаких альтернативных записей; GitHub только справочно; новые назначения ждут восстановления/отдельного OWNER GO. Это кооперативная защита от гонок, не OS ACL между агентами одного пользователя.

Снимок публикует исключительно WUA одним атомарным нумерованным коммитом GPT по №18/COMMIT-01; общий lock при снятии снимка и операциях checkout/merge, способных менять план. Не переключать ветку с активными неопубликованными правками. Владелец принимает main; локальный source of truth не перезаписывать старым снимком. Чужой код не менять.

Статусы: PLANNED, IN_PROGRESS, SUBMITTED (автор), VERIFIED (independent), ACCEPTED (owner), BLOCKED, OPEN, NOT_RUN. Evidence: TASK/SHA, verdict, scope, NOT RUN, ссылки. Один Integration ID с суффиксом этапа для пары строк; локальный TASK ID выдаёт каждый проект; TBD не является назначением. P0 разрешён; P1–P5 только план. После двух ACCEPTED с evidence WUA выполняет:

    python tools/shared_integration_plan.py archive --actor WUA --stage <STAGE> --expect <PLAN_SHA256>

Сначала проверенная запись архива, потом удаление обеих строк; сбой между действиями — повтор после read, не уничтожать архив.

## Общие ограничения

WUA → Client Bridge (HTTP+SSE) → Manager (существующий HTTPS+NDJSON); stateless контекст, без дубля GUI-чата/Global Prompt V4. Стабильный target_id, отдельный instance_id, идемпотентность, UNKNOWN без автоматического повтора. WUA владеет Turn, RAW, Workspace, памятью, инструментами/правами. DIRECT/SUPERVISED/ORCHESTRATED; server scope с первого инструмента. System/tool capability не имитировать, READY-only первый MVP. Никаких платных API, LIVE, изменения работающих моделей или production без отдельного GO. P5 «распределённый inference» = параллельные независимые запросы через Manager; разделение весов между машинами не согласовано.
