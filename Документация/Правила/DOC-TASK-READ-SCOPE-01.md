**Решение пользователя 2026-10-22.** Это правило для ChatGPT-координатора, который составляет БЛОК 1 любому локальному агенту (Claude, Codex и последующим). Координатор сам читает полный применимый маршрут проекта, сверяет реальные версии, личную карточку агента, существующие правила, активные TASK и `requires`. Исполнитель не должен повторно прочитывать весь общий маршрутизатор `000_Задачи для агента.md` или весь регламент `18` только потому, что их прочитал координатор: персональная карточка — его операционный вход. **Одинаковыми должны быть обязательные контракты, а не весь текст/история персональных и общего документов.**

**Каждая новая постановка содержит адресную «МАТРИЦУ ЧТЕНИЯ»:** `файл → точный устойчивый раздел/Rule-ID → зачем нужен → обязательно / при условии / полностью`. Давать не просто перечень названий. Для большой области выбрать нужный заголовок/Rule-ID и его вложенные подпункты; для действительно необходимого полного контекста прямо написать «прочитать полностью» и причину. Ссылки на нормативные правила не заменяют текст требования в TASK: ключевые запреты, write-scope, тесты, evidence и границы полномочий должны быть самодостаточны. Не копировать многократно одинаковые регламенты в каждую персональную карточку; исправить обнаруженное противоречие в единственном нормативном владельце и привести короткие персональные правила в соответствие.
