## DOC-WUA-LAUNCH-01 — Единая точка запуска Web Alarm Ultra и обязательный возврат из TEST

```rule-meta

```

**Решение пользователя 2026-10-27 / действует для ChatGPT-координатора, Claude 008, Codex 007 и будущих чатов.** Цель — один постоянный пользовательский запускатель `Start_WebAlarm.bat` в корне `ag_llm` (пока задача `CLAUDE-WUA-CHAT-LAUNCHER-001` не выполнена и независимо не принята, это **ТРЕБОВАНИЕ / НЕ ПОДТВЕРЖДЁННАЯ РЕАЛИЗАЦИЯ**). Пользователь запускает актуальный основной Web Alarm Ultra одним ярлыком с рабочего стола, а не разными BAT или отдельными пользовательскими Demo-версиями на каждом этапе. Внутренние Python-файлы/конфигурация могут меняться в рамках согласованных TASK; внешний BAT и ярлык остаются стабильными.

1. **STANDARD (по умолчанию).** Указывает на штатный основной `web_alarm.server` и согласованное постоянное хранилище. Перед открытием браузера отображается **зелёное** `СТАНДАРТНЫЙ ЗАПУСК — WEB ALARM ULTRA` (ровно когда фактическая цель, конфигурация, данные и защитные условия проверены как штатные). Не принимать наличие BAT само по себе за доказательство готовности рабочего режима; Stage1 Windows/visual и EVM проверки остаются OPEN до отдельной приёмки.
2. **TEST (исключение, явно назначенное).** Разрешён только для конкретной авторизованной тестовой работы с известным `TASK ID`, владельцем и scope; агент, которому поручено переключение, может изменить **внутреннюю маршрутизацию того же BAT** или явно выбранный профиль, но не создавать пользователю дополнительную точку запуска. **До запуска** обязательно видимое **красное** `ВНИМАНИЕ! НЕСТАНДАРТНЫЙ ТЕСТОВЫЙ ЗАПУСК`, имя тестовой конфигурации/цели и пометка `TEST`; не выдавать его за штатный режим. При невозможности цветного вывода — текстовое `[TEST / НЕСТАНДАРТНЫЙ]` без двусмысленности, при необходимости остановка для прочтения. При возможности добавлять метку в браузер, но цвет в браузере не подменяет проверку фактической маршрутизации.
3. **Изоляция/права.** TEST не использует реальные Workspace/TASK, постоянные реестры/журналы, секреты, live/paid API или штатный root, если это отдельно не одобрено. Не делать автоматические миграции, перепривязку к иной машине, восстановление данных или ослабление Host/Origin/token/Windows rights ради запуска. Стандартный BAT не должен незаметно переходить на новый пустой root при ошибке штатного.
4. **Возврат — обязательный барьер.** Автор тестового переключения по окончании теста восстанавливает сохранённую подтверждённую стандартную конфигурацию, проверяет фактический target/root и зелёный запуск, указывает evidence. **Перед принятием и началом каждой следующей технической TASK**, независимо от агента или чата, координатор/исполнитель вновь проверяет, что BAT стоит в STANDARD; если оставлен TEST, вернуть STANDARD **до начала** новой работы. Если восстановление нельзя подтвердить — `LAUNCHER_RESTORE_BLOCKED / NONSTANDARD`, красное предупреждение, стандартный запуск запрещён до разбирательства и пользователя информируют. Никакого молчаливого «зелёного» на тестовой цели.
5. **Учёт переключения.** В активной TASK/техническом отчёте фиксируются прежний target, новый target, причина, TASK ID, изменённые файлы, результаты стартовых проб, реальный root, способ rollback и доказательство возврата. Не запускать следующую TASK с незакрытым TEST routing. Временная правка запускателя допускается **только при согласованном scope**; это правило не является бессрочным разрешением Claude/Codex править произвольные файлы, сервер или активный БЛОК 1 и не размораживает B2/WA4-R/MCP.
6. **Переносимость §2.4 №37.** Определять рабочую папку относительно расположения BAT, корректно работать из ярлыка, с пробелами/кириллицей; не записывать абсолютный путь пользователя в постоянный launcher. Переносимость всего продукта пока `NOT VERIFIED`.

**Контроль при новой TASK:** `Launcher mode = STANDARD | TEST | RESTORE_BLOCKED | NOT_IMPLEMENTED`; для `TEST` указать владельца/TASK/цель и условие восстановления, для `STANDARD` проверенный обычный target. Правило является дисциплиной работы, а не заявлением о уже протестированной технической защите.
