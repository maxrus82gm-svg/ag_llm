Блок «Клиент»: профиль, идентичность, состояние, Подключить/Обновить каталог/Отключить. Без сканирования, без прямого обращения браузера к Manager. Привязка сохраняется между перезапусками без токена; точную политику повторного подтверждения identity согласовать. ## Статистика — ответственность Colibri
Manager измеряет производительность на вычислительном компьютере, сохраняет кумулятивные данные в локальной постоянной базе. SQLite — предложение, сначала проверить существующее storage/telemetry. Client агрегирует и передаёт сведения всех Manager, Studio отображает; один источник измерений, без второго счётчика в Studio. Серии по manager_id + model_key/verified weights revision + CPU/CUDA + существенная конфигурация/engine/hardware (потоки, GPU, context, offload, precision и т.д.). Разные слоты и перезапуски с сопоставимой конфигурацией пополняют общую серию; instance_id отдельно для live. Смена существенной конфигурации — новая серия. Неизвестные параметры не угадывать. Измерять фактический engine decode tok/s, не смешивать TTFT/prefill/сетевую задержку/total; native telemetry предпочтительно, derived явно маркировать, unknown nullable. Каждая подтверждённая завершённая генерация — один sample, дедуп по request/terminal; failed/cancelled/unknown отдельно. Не хранить prompt/ответы ради метрик. Накопительное среднее per-request tok/s, число измерений, время последнего; median/max/weighted throughput отдельные показатели по согласованию. Сопоставимость зависит от контекста/нагрузки/конкуренции, скорость не равна качеству модели.

## Live и idle
При генерации карточка конкретного экземпляра показывает текущую скорость LIVE tok/s, при простое/остановке — накопленное AVG tok/s для серии. Оба значения различимы; среднее доступно в деталях. При обрыве связи live unknown, историческое AVG с отметкой STALE и датой, при отсутствии измерений «—», не ноль. Модель не запускается ради статистики. Сохранять агрегаты после остановки Manager/компьютера. Реальное время — ограниченная частота обновления/подписка, не перегружать Manager, не смешивать с inference. При нескольких экземплярах live per-instance/request, aggregate per-series.
