### 3.2. Согласовать общую модель диалога

Подготовить точный технический контракт, который в дальнейшем будут использовать обе оболочки:

**Workspace → Chat → RAW Message → Turn → RUN / Provider Attempt.**

Для каждой сущности определить:

- постоянный идентификатор;
