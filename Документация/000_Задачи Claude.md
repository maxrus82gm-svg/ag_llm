- список сохранённых чатов текущего Workspace;
- история выбранного диалога;
- название или состояние модели из EVM;
- постраничная загрузка старых сообщений;
- неактивное поле ввода с объяснением, что отправка появится позднее.

- пустого Workspace;
- отсутствующей истории Ultra;
- пустого чата;
- повреждённого чата;
- частично повреждённой истории;
- недоступных данных;
- слишком большой истории;
- старой ошибки выполнения;
- сообщения пользователя без сохранённого ответа;
- недоступной или некорректной модели.

Старую ошибку нельзя показывать как успешный ответ нейросети или позднее без проверки включать в модельный контекст.

6. БЕЗОПАСНОЕ ЧТЕНИЕ И HTTP

Использовать контракт этапа 0 и требования stage1-handoff.md §5–6.

Планируемые HTTP маршруты:

GET /ui/ultra-chat/capability
GET /ultra/chat/workspaces
GET /ultra/chat/workspaces/<wa_workspace_id>/chats

Доступ к приватной истории — только с собственной read capability Ultra Chat. Токен из заголовка X-WebAlarm-Ultra-Chat-Token не смешивать с токеном folder picker.

Сохранить отдельные состояния disabled, non-loopback и invalid token.

Обязательные защиты:

- проверка Host, Origin, Sec-Fetch-Site, метода и HTTP-параметров;
- строгая принадлежность чата Workspace;
- совпадение идентификаторов с именами каталогов и RAW-файлов;
- защита от traversal, symlink, Windows junction/reparse и подмены целевого пути во время чтения;
- ограничение фактического количества прочитанных файлов, байтов и размера ответа;
- обнаружение повреждённого JSON и дубликатов ID;
- отсутствие записи в хранилище даже при ошибках;
- отсутствие утечек абсолютных путей, приватных данных и токена;
- безопасный текстовый вывод без исполнения HTML/JS из истории.

Ориентиры ограничений из Stage0:
один RAW — до 4 МиБ, суммарно до 2 000 файлов / 64 МиБ на чат. Физическое чтение должно останавливаться на границе, а не обрезаться после загрузки всего содержимого.

Не создавать собственную систему OS-user authentication и не объявлять локальный capability защитой от всех программ того же пользователя.

Нельзя повторять дефект прототипа v1: Ultra Chat должен работать независимо от того, включён Windows folder picker или нет.
