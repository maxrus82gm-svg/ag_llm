# История выполнения задач Ultra Desktop

**Назначение:** личный append-only архив Ultra Desktop для исходных утверждённых TASK, принятых AMENDMENT, фактических итогов (`PASS / PARTIAL / FAIL / BLOCKED / NOT RUN`), ссылок на полный `report.md` и manifest. Он **не** является источником самостоятельного выбора новых задач, нормативным регламентом или заменой общему `06_Журнал выполнения и отчёты.md`.

**Чтение:** Ultra Desktop не сканирует и не загружает эту историю по собственной инициативе. При завершении **своей** TASK вправе лишь добавить новую запись и повторно прочитать добавленный фрагмент, если это предписано персональной карточкой/утверждённым БЛОКОМ 1. Иные архивные сведения передаёт адресно ChatGPT-координатор. Не перечитывать весь архив, не изменять старые записи и не превращать прошлые статусы в новые.

**Схема следующей записи (после реально назначенной TASK):**
- Дата, TASK ID, исполнитель/режим, исходный `БЛОК 1` и все разрешённые AMENDMENT.
- Утверждённый `read_scope/write_scope`, запреты, фактические пути.
- Реально созданные и повторно прочитанные файлы; выполненные тесты с командами/exit code или `NOT RUN`.
- Factual результат, `BLOCKED`-диагностика, findings, итог `RESULT READY / AWAITING INDEPENDENT VERIFICATION` или честный иной статус.
- Относительный locator `GigaCode_Lab/.../report.md` и manifest/evidence; дата/readback новой записи.
- Независимый вердикт не выдумывать: он остаётся у ChatGPT в БЛОКЕ 4 и общем журнале `06`.
