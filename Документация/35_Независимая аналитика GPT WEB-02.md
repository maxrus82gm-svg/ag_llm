**Назначение:** хранить независимый технический разбор GPT по вопросам из [[33_Вопросы и проблемы WEB-02, требующие решения]].

Для каждой записи указывать:
- ID `WEBQ-xxx`;
- модель / режим, если важно;
- изученные материалы;
- собственные выводы;
- найденные риски и противоречия;
- альтернативы;
- рекомендуемое направление;
- что осталось проверить.

Этот документ **не является источником архитектурной истины** и сам по себе ничего не разрешает менять.
