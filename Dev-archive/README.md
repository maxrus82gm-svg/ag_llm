# Dev archive

Содержимое `Dev-archive` не является current runtime.

- `patches/` — старые одноразовые patch/install scripts;
- `snapshots/` — старые снимки файлов;
- `legacy/` — старые реализации и дубли;
- `notes/` — исторические тестовые и установочные заметки.

Current source of truth находится в корне проекта. Использовать файлы из этого архива как runtime запрещено.
