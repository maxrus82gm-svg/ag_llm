# Ultra Chat — ручной проход пользователя / WEB21 / 04.11.2026

Источник: сообщения и скриншоты пользователя в текущем чате. Сами скриншоты здесь не экспортировались.
Режим запуска STANDARD сообщил пользователь, системный readback режима отдельно не запускался.

Подтверждено по скриншотам: Workspace с именем «123» зарегистрирован в операторской панели из ранее существующей папки. В Ultra Chat виден «Чат 1» с ранее сохранёнными сообщениями, а не вновь сгенерированным ответом. Пользователь создал «Чат 2» с названием по умолчанию, затем переименовал его в «Тест интерфейса». Отправка сообщений оставалась отключена.

Пожелания пользователя: исключить переход в операторскую панель при кнопке создания Workspace; выбирать папку нативно, название по умолчанию брать из папки; древовидный Workspace → диалоги; видимые кнопки плюс/карандаш у нужного объекта; постоянная подсветка выбранного.

NOT RUN: F5/перезапуск и readback имени «Тест интерфейса» после F5; новый UX в реальном браузере; picker при отмене, адаптивная верстка, нативный GUI, независимая полная регрессия и настоящие LLM-запросы.
