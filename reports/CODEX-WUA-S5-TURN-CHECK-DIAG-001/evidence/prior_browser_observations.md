# Уже проведённая диагностика — восстановленные наблюдения

Дата: 2026-11-07; происхождение: реальные ответы инструментов в этом чате.
Это очищенная реконструкция, сохранённая при формальной сдаче. Полный первичный
протокол браузера и HAR ранее в проект не экспортировались. Новый браузерный
прогон при closeout не выполнялся; эти записи не являются повторным тестом.

1. Нативный доступ к окну Chrome `Web Alarm Workspace` сначала не удался:
   отсутствовало AX-состояние, screenshot получил `FrameArrived timed out`,
   затем доступ остановился из-за невозможности достоверно определить URL.
   Первая сдача PARTIAL честно указала, что браузерный тест ещё не выполнен.
2. После повторного поручения пользователя найден уже работающий процесс
   `review_fixture.py`, PID 27464, listener `127.0.0.1:53505`. Новый сервер и
   профиль не запускались. Во встроенном браузере открыта новая вкладка этого
   же сервера. Видны `TEST · OFFLINE`, `S5_SMOKE_01`, `S5_CHAT_03`.
3. Первая попытка автоматического click открыла список моделей. В истории не
   было `S5_TURN_DIAG_01`, текст оставался в composer. Это ошибка UI-наведения
   исполнителя, не подтверждённая отправка и не дефект кнопки Turn.
4. После проверки отсутствия отправки сообщение `S5_TURN_DIAG_01` отправлено
   клавишей Enter. Сразу затем активирована кнопка проверки клавишей Enter.
   Полученный AX-снимок: input disabled, значение `S5_TURN_DIAG_01`, статус
   `Принимаем TEST-запрос…`, отмена доступна, повтор/восстановление disabled.
   Следовательно нажатие во время отправки состоялось. Ответ GET в активной
   фазе отдельно не сохранён: этот снимок НЕ доказывает возврат ATTEMPTING
   или воспроизведение ошибочной метки interrupted в нашем запросе.
5. После завершения снова активирована проверка. Видны ровно одна пара для
   теста: user `S5_TURN_DIAG_01`, assistant `Ответ на: S5_TURN_DIAG_01`.
   Время в UI: user 17:14:00, assistant 17:14:01 (часовой пояс этих полей
   отдельно не устанавливался). Статус `TEST: ответ сохранён. · gigachat_2`.
6. Выполнен reload (аналог F5), дождались тестового сообщения и снова
   активировали проверку. Пара и тот же успешный статус сохранились;
   `isEnabled()` для кнопки проверки вернул true. Новая отправка не делалась.
7. Отдельные read-only GET к этому же TEST-серверу подтвердили TEST_OFFLINE,
   SUCCEEDED, одинаковое представление latest и by-key, полную историю,
   один user `S5_TURN_DIAG_01`, outcomes request/completed. Очищённые поля
   сохранены в `prior_http_snapshot.json`. Capability token не сохранялся.
   Русский текст HTTP в консоли был повреждён кодировкой вывода; это не
   доказательство повреждения RAW. Ответ в браузере читался корректно.

Отмена в этом прогоне не нажималась. Наблюдение пользователя «после отмены
неопределённый исход, после F5 исчезновение» не воспроизведено исполнителем.
Нет пары RAW/hash до и после, identity отменённого Turn и трассы GET/POST
для этого эпизода. Пользовательский screenshot показывает активный запрос
с меткой «Прервано», но не отмену и не состояние после F5.

Прежняя правка русских надписей сделана позже этого браузерного прогона.
Перезапуск/визуальная проверка новой надписи после этой правки не выполнялись.
