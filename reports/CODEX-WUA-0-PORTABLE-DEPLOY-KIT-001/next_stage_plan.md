# Следующий этап — proposal, не разрешение

1. WEB_10 независимо проверяет **этот toolkit**: source, контракт 55 полей,
   source-pinned 62-case synthetic report, privacy, blocked Apply/rollback,
   actual read-only output и manifest. Не считать AST/metadata security PASS.
2. Пользователь указывает уже доступную разрешённую script execution среду и
   source/asset inputs; runtime source archive передаётся offline с ожидаемым
   hash. Для Windows 5.1/Restricted нужно отдельное решение по разрешённой
   среде/политике, не автоматический Bypass и не обход GPO.
3. Одна отдельная implementation/proof TASK: reviewed user-mode security
   backend + trusted host/ledger identity и его build/signature; disposable
   Windows lab с доказанным отсутствием внешнего/host-relay пути **до** any
   native/rule/account experiments. Привилегии setup ограничить lab и manifest.
4. В этой lab подтвердить actual ALE SID matching, loopback/bind guard,
   predicate domain/compares/arbitration, BFE/boot/flows, DNS/COM/BITS/crypto
   delegation, actual ACL, noninteractive startup/job/descendants и quiescence.
   Нужны независимые attempts/process/flow oracles, loss counters и negative
   controls, а не отсутствие пакетов. Реальные public IP/DNS targets запрещены.
5. Только после независимого PASS backend и **нового USER GO** изменять release
   capability на реальный Apply. Это изменение исходников/доверенного helper,
   не поле JSON и не флаг force. Предварительно создать host-bound private ledger,
   exact approval и rollback; identities новые локальные, все непроверенные
   install/startup objects disabled. На working Windows до этого ничего не применять.
6. Native client, V2Ray live route, hosted activation и четыре ordinary Chat
   MCP-вызова/receipt — последующие отдельные USER gates. Hold остаётся в силе.

Не нужен новый общий архитектурный круг исследования: известны конкретные
блокеры backend/proofs и формат безопасного следующего пакета. Не выбирать
shared V2Ray с DIRECT, широкое localhost allowance или глобальную настройку
firewall как сокращение пути. UI ChatGPT вне scope будущих C/B filters.
