Для восстановления отдельного документа выбрать его точный snapshot из baseline, проверить hash и сравнить текущий документ с hash применённой версии в manifest. Если совпадает — можно восстановить исходные байты только этого файла по явному решению о rollback. Если есть более поздняя правка — сначала reconcile, не слепой overwrite. Старые №001 и исходные части №05/06 не удаляются ради отката. Git rollback не использовался и не требуется для локального восстановления байтов.
