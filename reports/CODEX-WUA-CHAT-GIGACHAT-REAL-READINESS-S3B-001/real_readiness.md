# H34 REAL readiness / mandatory remaining gates

H34 is OFFLINE engineering evidence, not an enable-LIVE release. REAL authority acquisition always refuses, the real OAuth gate refuses before cached credentials, and the HTTP adapter can construct only MockTransport. No env/JSON/UI/launcher Boolean or URL activates network.

## Prepared and testable

- Seven legacy source sites delegate to a common guarded client and the accepted H33 byte transport. Final body is serialized before S2; no JSON encoding follows admission. The original application parsers and provider events remain responsible for their existing output schemas.
- Server-owned TEMP owner, immutable profile/effective policy, real Run Store identity and durable owner nonce; existing S3a ledger. One in-flight attempt and exact readbacks. Unknown/corrupt/old/capacity-limited ledger refuses, never bootstraps an empty history.
- Exact attempt/role/model/snapshot metadata, endpoint, wire/hash and policy/profile binding. Body/model substitution, wrong/injected client, receipt replay and owner change cannot authorize an HTTP fixture call.
- Reserve/SENT/terminal one-shot chain, cancel/deadline, late response handling and no retry. A transport callback cannot erase cancellation on its owning task by uncancelling itself. UNKNOWN retains liability and blocks ambiguous continuation.
- Existing Ordinary Turn/RAW/per-chat usage/settings and launcher profiles are reused. Legacy Run authority explicitly refuses a claimed Turn ID; actual Turn sends continue to use the existing TurnService admission.

## Operational limits of the current preparation

Default legacy calls without a server owner now fail closed before token/HTTP. This intentional safety change includes internal MCP/Tk callers; no legacy allow shim is retained. STANDARD/Tk source, launchers and data are not edited. Production owner provisioning is not secretly created from browser input or a live Workspace.

An unresolved durable owner, reserved/SENT attempt, lost terminal ACK, cancellation or transport uncertainty remains blocked. Even a cleanly closed owner cannot replay an old attempt ID. Reconciliation is a separate explicit operation; H34 does not free reservations or override old owner/audit facts for convenience.

Existing legacy provider-event observers can fail independently; S3a still retains the real admitted attempt and supplied usage. A legacy display summary may remain incomplete when its observer fails. That reporting limitation is distinct from zero liability and must not be presented as complete per-chat accounting for all agent routes. Ordinary H29/H32/H33 usage is unchanged.
