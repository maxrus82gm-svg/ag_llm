Validate tunnel-client configuration before starting the daemon

Usage:
  tunnel-client doctor [flags]

Flags:
      --admin-ui.log-buffer-events int                   Number of recent log events to keep in memory for the embedded web UI and export archive (env.ADMIN_UI_LOG_BUFFER_EVENTS, max 100000) (default 2000)
      --allow-remote-ui                                  Allow remote access to the embedded web UI and log endpoints (env.ALLOW_REMOTE_UI)
      --ca-bundle string                                 Path to PEM CA bundle for outbound TLS trust (additive to system trust) (env.CA_BUNDLE)
      --cloudflared.managed                              Fetch the managed Cloudflare Tunnel runtime token from the control plane on startup (env.CLOUDFLARED_MANAGED)
      --cloudflared.path string                          Path to the bundled cloudflared executable; defaults to the executable beside tunnel-client (env.CLOUDFLARED_PATH)
      --cloudflared.ready-timeout duration               Maximum time to wait for bundled cloudflared to report ready (env.CLOUDFLARED_READY_TIMEOUT) (default 30s)
      --cloudflared.token string                         Reference to an environment variable or file containing a pre-provisioned Cloudflare Tunnel token (format env:VARNAME or file:/path; env.CLOUDFLARED_TUNNEL_TOKEN)
      --config string                                    Path to YAML config file (env.TUNNEL_CLIENT_CONFIG). Precedence: flags > environment > YAML > defaults
      --control-plane.api-key string                     Reference to environment variable or file containing the control-plane API key (format env:VARNAME or file:/path/to/secret)
      --control-plane.base-url string                    Tunnel control-plane base URL (env.CONTROL_PLANE_BASE_URL) (default "https://api.openai.com")
      --control-plane.client-cert string                 Path to PEM client certificate for control-plane mTLS (format <path|env:VAR|file:/path>) (env.CONTROL_PLANE_CLIENT_CERT)
      --control-plane.client-key string                  Path to PEM client private key for control-plane mTLS (format <path|env:VAR|file:/path>) (env.CONTROL_PLANE_CLIENT_KEY)
      --control-plane.extra-headers stringArray          Additional HTTP headers to send to the tunnel control-plane (format 'Key: Value', repeatable; values accept env:VAR or file:/path) (env.CONTROL_PLANE_EXTRA_HEADERS)
      --control-plane.http-proxy string                  Outbound HTTP proxy for the control plane (format <url|env:VAR>)
      --control-plane.initial-poll-timeout duration      Maximum requested wait for the first poll, capped by poll-timeout; does not shorten the client deadline (env.CONTROL_PLANE_INITIAL_POLL_TIMEOUT) (default 30s)
      --control-plane.max-inflight int                   Capacity of the local polled-command buffer; polling pauses while the buffer is full (env.CONTROL_PLANE_MAX_INFLIGHT_REQUESTS, max 10000) (default 20)
      --control-plane.organization-id string             Organization ID to send as OpenAI-Organization on tunnel control-plane requests (env.CONTROL_PLANE_ORGANIZATION_ID)
      --control-plane.poll-channel stringArray           Channel to drain from the control plane (repeatable; env.CONTROL_PLANE_POLL_CHANNELS)
      --control-plane.poll-deadline-guardrail duration   Extra time after the requested long-poll wait before the control-plane HTTP/context deadline (env.CONTROL_PLANE_POLL_DEADLINE_GUARDRAIL) (default 5s)
      --control-plane.poll-timeout duration              Long-poll timeout when fetching commands from the control plane (env.CONTROL_PLANE_POLL_TIMEOUT) (default 30s)
      --control-plane.tunnel-id string                   Identifier for this client/tunnel (env.CONTROL_PLANE_TUNNEL_ID)
      --control-plane.url-path string                    Optional URL path appended to the control-plane base URL before tunnel-client adds its /v1/... routes (env.CONTROL_PLANE_URL_PATH)
      --explain                                          Explain why failed checks matter and what to do next
      --harpoon.additional-transport stringArray         Additional harpoon transports (http-streamable) (env.HARPOON_ADDITIONAL_TRANSPORTS)
      --harpoon.allow-plaintext-http                     Allow http:// harpoon targets and redirects (env.HARPOON_ALLOW_PLAINTEXT_HTTP)
      --harpoon.capture-payloads                         Capture request/response payloads for the Harpoon admin UI (debug only). (env.HARPOON_CAPTURE_PAYLOADS)
      --harpoon.hosts-include-loopback                   Treat loopback hosts as private for Harpoon auto-registration (env.HARPOON_HOSTS_INCLUDE_LOOPBACK) (default true)
      --harpoon.hosts-include-private                    Treat private IPs as private for Harpoon auto-registration (env.HARPOON_HOSTS_INCLUDE_PRIVATE) (default true)
      --harpoon.hosts-include-regex stringArray          Host regex patterns treated as private for Harpoon auto-registration (repeatable) (env.HARPOON_HOSTS_INCLUDE_REGEX)
      --harpoon.hosts-include-suffix stringArray         Host suffixes treated as private for Harpoon auto-registration (repeatable) (env.HARPOON_HOSTS_INCLUDE_SUFFIX)
      --harpoon.http-proxy string                        Outbound HTTP proxy for Harpoon requests (format <url|env:VAR>)
      --harpoon.max-redirects int                        Maximum number of harpoon redirects (env.HARPOON_MAX_REDIRECTS) (default 5)
      --harpoon.max-response-bytes int                   Maximum harpoon response size in bytes (env.HARPOON_MAX_RESPONSE_BYTES) (default 102400)
      --harpoon.target stringArray                       Harpoon target mapping (format 'label=...,url=...,unix-socket=...,desc=...') (env.HARPOON_TARGETS)
      --health.listen-addr string                        Address the health HTTP server listens on (ip:port). Use :8080 to listen on all interfaces, or 127.0.0.1:0 to request a loopback ephemeral port from the OS. Ignored when health.unix-socket is set. (env.HEALTH_LISTEN_ADDR) (default "127.0.0.1:8080")
      --health.show-details                              Include component details in GET /health by default; details=true or details=false overrides each request (env.HEALTH_SHOW_DETAILS)
      --health.unix-socket string                        Unix socket path for the health HTTP server. When set, tunnel-client serves health over the socket instead of binding TCP. (env.HEALTH_UNIX_SOCKET)
      --health.url-file string                           File to write the health base URL to after startup (env.HEALTH_URL_FILE)
  -h, --help                                             help for doctor
      --http-proxy string                                Global outbound HTTP proxy (applies to control-plane, MCP, and Harpoon) (format <url|env:VAR>)
      --json                                             Emit machine-readable JSON output
      --log.file string                                  Log file path; defaults to stdout when empty (env.LOG_FILE) (default "stdout")
      --log.format string                                Log format (struct-text, json) (env.LOG_FORMAT)
      --log.http-raw-unsafe                              Log full raw HTTP requests and responses (including bodies/headers). WARNING: May include PII or sensitive data. Use only for debugging. (env.LOG_HTTP_RAW_UNSAFE)
      --log.level string                                 Log level (debug, info, warn) (env.LOG_LEVEL) (default "info")
      --mcp.client-cert string                           Path to PEM client certificate for MCP mTLS (format <path|env:VAR>) (env.MCP_CLIENT_CERT)
      --mcp.client-key string                            Path to PEM client private key for MCP mTLS (format <path|env:VAR>) (env.MCP_CLIENT_KEY)
      --mcp.command stringArray                          Command to launch an MCP server over stdio (repeatable; format command=...,channel=...) (env.MCP_COMMAND)
      --mcp.connection-max-ttl duration                  Maximum lifetime of MCP transport connections (env.MCP_CONNECTION_MAX_TTL) (default 10m0s)
      --mcp.discovery-extra-headers stringArray          Static HTTP headers to send to MCP discovery/probe requests for the configured MCP server origin (format 'Key: Value', repeatable; values accept env:VAR or file:/path) (env.MCP_DISCOVERY_EXTRA_HEADERS)
      --mcp.extra-headers stringArray                    Static HTTP headers to send to the configured MCP server origin (format 'Key: Value', repeatable; values accept env:VAR or file:/path) (env.MCP_EXTRA_HEADERS)
      --mcp.forward-trace-context                        Opt in to forwarding traceparent/tracestate through MCP params._meta over stdio and HTTP (env.MCP_FORWARD_TRACE_CONTEXT)
      --mcp.http-proxy string                            Outbound HTTP proxy for MCP (format <url|env:VAR>)
      --mcp.max-concurrent-requests int                  Maximum number of requests actively dispatched to the MCP server (env.MCP_MAX_CONCURRENT_REQUESTS) (default 10)
      --mcp.oauth-trusted-origin stringArray             Additional HTTP(S) origin trusted for OAuth discovery (repeatable; origin only, without a path) (env.MCP_OAUTH_TRUSTED_ORIGINS)
      --mcp.server-url stringArray                       Target MCP server URL (repeatable; format url=...,channel=...,unix-socket=...,http-proxy=...,client-cert=...,client-key=...) (env.MCP_SERVER_URL)
      --mcp.startup-wait-timeout duration                Maximum opt-in startup wait for the main MCP HTTP listener before first poll (env.MCP_STARTUP_WAIT_TIMEOUT)
      --mcp.stdio-send-initialized-notification          Opt in to sending notifications/initialized after a successful stdio initialize response (env.MCP_STDIO_SEND_INITIALIZED_NOTIFICATION)
      --open-web-ui                                      Open the embedded web UI in your default browser on startup (env.OPEN_WEB_UI)
      --pid.file string                                  File to write the tunnel-client process ID to (env.PID_FILE)
      --profile string                                   Profile name to load from the profile directory (env.TUNNEL_CLIENT_PROFILE)
      --profile-dir string                               Directory containing profile YAML files (env.TUNNEL_CLIENT_PROFILE_DIR; default $XDG_CONFIG_HOME/tunnel-client or ~/.config/tunnel-client)
      --profile-file string                              Path to a specific profile YAML file (env.TUNNEL_CLIENT_PROFILE_FILE)
      --proxy.check-interval duration                    Interval between proxy connectivity checks (env.PROXY_CHECK_INTERVAL) (default 1m0s)
