Tunnel client for the OpenAI MCP control plane.
Use it to connect a local or private MCP server to the OpenAI control plane over an outbound tunnel.
When it starts, it runs the long-lived tunnel daemon and exposes local operator surfaces at /healthz, /readyz, and /ui.
Fastest Codex terminal path: tunnel-client codex assistant "Summarize what tunnel-client is doing in this checkout."

Canonical setup URLs:
  Tunnels management: https://platform.openai.com/settings/organization/tunnels
  Runtime API keys: https://platform.openai.com/settings/organization/api-keys
  Admin API keys: https://platform.openai.com/settings/organization/admin-keys
  ChatGPT connector settings: https://chatgpt.com/#settings/Connectors

Usage:
  tunnel-client [command]

Available Commands:
  admin          Administrative operations for the tunnel control plane
  admin-profiles Manage tunnel-client admin profiles used by runtimes commands
  cloudflared    Inspect the bundled Cloudflare Tunnel companion
  codex          Use the Codex assistant surface and inspect CLI/app-server/plugin wiring
  completion     Generate the autocompletion script for the specified shell
  dev            Developer helpers for local tunnel-client validation
  doctor         Validate tunnel-client configuration before starting the daemon
  health         Probe tunnel-client /healthz and /readyz for a live daemon
  help           Show help for an agent-first topic or subcommand
  init           Create a runnable first-use tunnel-client profile
  profiles       Manage tunnel-client YAML profiles
  run            Run the tunnel client poller
  runtimes       Manage native tunnel-client runtimes

Flags:
