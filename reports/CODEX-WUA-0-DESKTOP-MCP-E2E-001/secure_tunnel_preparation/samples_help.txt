List or inspect built-in tunnel-client profile samples

Usage:
  tunnel-client profiles samples [command]

Available Commands:
  list        List built-in profile sample names
  show        Show a built-in profile sample plus required inputs

Flags:
  -h, --help   help for samples

Global Flags:
      --profile-dir string   Profile directory override

Use "tunnel-client profiles samples [command] --help" for more information about a command.
