# Короткая проверка P0/P1

1. Запустить обычный `Start_WebAlarm_Test.cmd`, создать Workspace и чаты A/B.
2. В A отправить короткое сообщение. Под историей должен появиться блок «TEST · синтетические токены». Для штатного fake без usage ожидается UNKNOWN; это корректно, нулевые реальные расходы не выдумываются.
3. Раскрыть «Настройки этого чата»: исходно 250000 и 10000. Установить 123456 и 20000, нажать «Сохранить». Это предпочтения; автосжатие выключено, provider cap не подтверждён.
4. Нажать F5 и открыть A: значения должны сохраниться. Перейти в B: там остаются свои defaults и свои счётчики.
5. Вернуться в A, изменить выбранную тестовую модель: настройки должны остаться. Несохранённый ввод не должен исчезать от обычного обновления истории.
6. Для остановки нажать Enter в окне запуска. TEST очищает TEMP чаты и настройки; следующий запуск начинается пустым. STANDARD не использовать для этой проверки.

Известные input/output/reasoning проверены синтетическими injected-response тестами. Настоящих провайдеров задача не подключала. REAL остаётся закрытым до отдельного S3b/USER GO.
