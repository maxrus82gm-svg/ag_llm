# Ручной smoke после восстановления UI доступа

На локальном Web Alarm с тестовым Workspace, без запуска LIVE и без «Проверить чат»:

1. Открыть EVM, закрепить две карточки через `⧉`/Ctrl+клик, переместить внутри страницы, сделать F5. Проверить те же карточки и расположение.
2. Нажать `↗` у трёх разных моделей; убедиться, что открылись три отдельных окна и карточки остались в EVM. Перетащить два окна на второй монитор. Закрыть одно и проверить, что модель не отключилась и другие окна остались.
3. Внешнее окно оставить открытым; в основном окне перейти в Ultra Chat и сделать F5. Проверить независимость, синхронизацию кнопки и статуса через сервер.
4. В одном внешнем окне включить «Поверх всех окон»; поместить другое приложение поверх и проверить реальное наложение. Выключить и проверить обычный оконный режим. Повторить для второго окна и зафиксировать, допускает ли браузер два PiP одновременно.
5. Выключить одну модель, проверить её отсутствие в picker, чтение старого чата и запрет новой отправки только к ней. Вернуть модель; проверить сохранность чата. Не нажимать LIVE start и «Проверить чат» без отдельного GO.

Эти шаги — будущая физическая проверка, **не утверждение об их прохождении**.
