# Window review — evidence boundary

Chrome 157 на Windows, два дисплея 2560×1440 (DISPLAY1 x=0..2559, DISPLAY2 x=2560..5119). Локальный изолированный Web Alarm сервер был временно запущен на `127.0.0.1:52920` и остановлен. Инструмент Computer Use остановил сеанс при попытке перейти к этому URL: он не смог достаточно надёжно определить текущий browser URL Windows для соблюдения своей политики. Поэтому физические WINDOW MOVE и TOPMOST **NOT RUN**, даже если JS mock PASS.

В коде `window.open` создаёт обычное отдельное окно для каждой модели. Ему можно вручную назначить другой монитор средствами Windows; программная установка координат не требуется и не проверялась. Документированный браузерный механизм Document Picture-in-Picture создаёт окно поверх прочих приложений при пользовательском действии. Его жизнь связана с открывшей страницей; число одновременных PiP зависит от реализации браузера. Реальное наложение, независимость нескольких PiP и фокус между мониторами необходимо проверить в Windows. Отказ `requestWindow` отображает ошибку; обычное окно остаётся.

Изолированный smoke без paid API описан в `user-smoke.md`. Никаких выводов о физическом topmost по одной DOM-проверке не сделано.
