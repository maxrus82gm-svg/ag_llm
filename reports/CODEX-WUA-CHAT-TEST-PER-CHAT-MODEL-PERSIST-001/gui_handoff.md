# Повторная проверка владельцем — USER UX PENDING

Пакет меняет только сохранение модели в текущем Ordinary TEST. Авторские автоматические тесты не являются личной GUI-проверкой владельца.

1. Запустить прежний `Start_WebAlarm_Test.cmd`, дождаться красного TEST/OFFLINE и создать временный Workspace с чатами A и B.
2. В A выбрать Lightning, в B — Ultra. Переключить A → B → A: подпись модели должна соответствовать каждому чату.
3. Отправить короткий TEST-текст в A, затем нажать F5. Должны сохраниться история и Lightning; после открытия B — Ultra. Отправки остаются синтетическими.
4. Проверить второй временный Workspace: его выбор независим. Для чата без сохранённого выбора допустима первая доступная модель TEST-каталога.
5. Завершить TEST штатно через Enter в его консоли. Новый TEST-процесс создаёт пустое временное хранилище и не наследует выбор предыдущей сессии. STANDARD и рабочие данные для этой проверки не нужны.

При ошибке сохранения или неподтверждённой модели должно быть видимое предупреждение; приложение не должно молча показывать другую модель как восстановленную. Для продолжения выбрать доступную модель повторно. Физические ошибки диска владелец воспроизводить не должен — они покрыты OFFLINE-тестами.

FOLLOWUP: обычный чат без обязательного Workspace — отдельное пользовательское пожелание, в данной задаче не реализовано. REAL HOLD и существующая процедура независимой Windows-проверки сохраняются.
