# Авторский engineering review / 2026-11-15

- Причина подтверждена RED на поставляемом UI и TEST HTTP: TEST branch не сохранял model_ref; после F5/смены чата использовал общее состояние страницы/первую модель. STANDARD имел отдельный контракт, который не переносился на TEST.
- Исправление использует прежний registry и существующий metadata.json writer. Новый ключ `test_chat_model` находится внутри metadata конкретного Workspace/Chat; нет глобального EVM-selection, нового storage, ledger или модели каталога. Чтение без ключа возвращает начальное значение без записи. Испорченный/удалённый model_ref даёт 409; явный допустимый POST может восстановить настройку.
- Capability `chat_model_preferences` выдаёт только OrdinaryCore TEST. Метод требует exact OrdinaryCoreChatService; у STANDARD свой /model handler и `ordinary_chat_model`. Его исходный модуль, server/factory/admission/transport, launcher и профили остаются byte-identical. Дополнительные UI branches активны только при TEST capability, старая Stage5 rollback ветка сохраняется.
- Сохранение модели проходит под shared workspace writer, с identity/Chat validation и `_replace_verified`. ROOT/провайдер/authority нельзя передать в body. Любые дополнительные поля/неизвестные модели отвергаются. READ/WRITE capabilities остаются раздельными, read token не даёт POST. API не инициирует Turn, RAW, usage или enrollment.
- UI ждёт подтверждённого POST; при неудаче явно сообщает об ошибке и не считает новый выбор сохранённым. Чтение/запись используют epoch + model revision. Поздние ответы другого чата/устаревшего чтения не заменяют текущую модель. Новая отправка ждёт восстановления модели; проверка уже принятого Turn остаётся доступна. Pending key/text/model принадлежат принятому Turn, а не настройке следующего сообщения.
- Дополнительный review воспроизвёл stale picker при смене чата во время сохранения (picker_context_red). TEST закрывает прежний picker при смене контекста; модель следующего чата и её aria-индикация не остаются в старом меню. STANDARD branch не менялся. Окончательный UI suite повторён на этой версии.
