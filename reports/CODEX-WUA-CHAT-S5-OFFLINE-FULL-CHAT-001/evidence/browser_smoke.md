# Windows in-app Chromium · actual loopback browser smoke

6 ноября 2026. Запуск `python -B -X utf8 reports/CODEX-WUA-CHAT-S5-OFFLINE-FULL-CHAT-001/review_fixture.py --web-smoke` в одноразовом TEMP. Открывались только локальные адреса. UI-действия выполнены через computer-use, скрытая вкладка. Ввод синтетический.

Первый прогон на порту 54907 показал баннер TEST, но после нажатия кнопки Workspace UI выдал «Не удалось создать временный TEST Workspace. Обновите список.» Нативный prompt не появился в этой вкладке. Встроенная форма заменила prompt, подсказки TEST и общая панель действий были уточнены.

Повторный прогон на порту 55468 зафиксировал следующие видимые состояния.

- `TEST · OFFLINE`. До создания диалога поле «Сообщение» и кнопка «Отправить» отключены. Встроенная форма приняла «Браузерный TEST», затем создан первый чат «Браузер A».
- Два сообщения создали два ответа «Ответ на: Первая проверка браузера» и «Ответ на: Вторая проверка браузера». Между отправками выбрана GigaChat 2 Pro через штатный список моделей.
- После F5 видны четыре RAW-сообщения и `TEST: ответ сохранён. · gigachat_2_pro`. Текущий выбор в новой вкладке может вернуться к первой модели. Модель сохранённого Turn показана отдельно.
- «Браузер B» открылся пустым. Во время TEST-отправки «Только диалог B» кнопка «Отменить» сработала. После F5 показаны только user RAW и «Исход неизвестен. Повтор ключа проверит сохранённые факты; повторного исполнения нет.» Доступна кнопка «Повторить / восстановить».
- После явного повтора и возврата в A история содержит только две исходные пары. Read-only DOM oracle проверил отсутствие «Только диалог B» в A.

При остановке fixture в выводе оставался Windows `WinError 10053` от разорванного loopback HTTP-соединения. Наблюдение сохранено как частичный консольный фрагмент, полный traceback браузерного прогона не записан. Отдельный воспроизводящий тест `lost_reply_red` сохранил полный stderr и продемонстрировал второй HTTP ответ 500 поверх потерянного подтверждения. Финальная регрессия проверяет scoped обработку разрыва и same-key replay. Видимые браузерные сценарии выше выполнены до этой последней правки доставки ответа. HTTP/Tk/Node регрессия запущена на итоговых исходниках.
