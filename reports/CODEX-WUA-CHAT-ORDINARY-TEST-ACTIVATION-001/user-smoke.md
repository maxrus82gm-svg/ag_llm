# Короткая пользовательская проверка

1. Запустить существующий `Start_WebAlarm_Test.cmd`. Дождаться красного TEST-предупреждения и браузера. В окне запуска появится «Ordinary Core Chat».
2. Создать временный Workspace и чат A, выбрать доступную модель. Отправить «Первое A», затем «Второе A». Ответ должен быть явно TEST/fake.
3. Создать чат B, отправить «Только B». Вернуться в A: история B в нём не появляется.
4. Нажать F5 при работающем TEST: выбрать A и проверить сохранённые пары сообщений. Дополнительно можно отправить третье короткое сообщение A.
5. Для остановки нажать Enter **в окне запуска**. Сервер остановится, временные чаты будут удалены. Закрытие одной вкладки браузера сервер не останавливает. Следующий TEST-запуск создаст новое пустое временное хранилище.

STANDARD и реальные LLM здесь не проверять. Большие сообщения пока ограничены прежним offline fixture. Отдельное отображение input/output/reasoning/UNKNOWN отложено.

Откат: в `web_alarm/launch_test_config.json` выбрать `active: "stage5-offline"`; старый профиль сохранён. В штатной работе сейчас выбран `ordinary-core-offline`.
