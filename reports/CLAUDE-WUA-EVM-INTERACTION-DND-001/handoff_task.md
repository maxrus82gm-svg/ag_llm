# TASK: CLAUDE-WUA-EVM-INTERACTION-DND-001

**Название:** EVM — раскрытие карточек внутри списка, боковой предпросмотр и полноценное перетаскивание мышью.

## 1. Причина постановки

Пользователь проверил компактный интерфейс EVM на практике.

Четырёхколоночная компоновка признана удачной, однако обнаружен серьёзный недостаток взаимодействия: подробная карточка появляется поверх компактных карточек и мешает работе мышью.

В опубликованной реализации `web_alarm/ui.py` наведение запускает `peekHover()` через 120 мс, клик закрепляет плавающую панель, а `positionPeek()` располагает её с привязкой к исходной карточке. Нативные обработчики drag-and-drop реализованы, но реальное перетаскивание мышью Windows в отчёте предыдущей задачи отмечено как `NOT RUN`.

Таким образом, наличие кода и синтетических тестов не подтверждает удобство реального перетаскивания.

**Цель:** превратить EVM в рабочую интерактивную доску, где карточки можно раскрывать, переставлять и добавлять в избранное обычными действиями мыши без конфликтов между просмотром и перемещением.

## 2. Обычный клик — раскрытие внутри колонки

Основное действие — клик левой кнопкой по компактной карточке.

- Карточка разворачивается **на своём месте вниз**, непосредственно под компактным заголовком.
    
- Остальные карточки этой колонки сдвигаются вниз обычным потоком документа.
    
- Карточки выше не перемещаются.
    
- Повторный клик сворачивает карточку.
    
- Допускается несколько одновременно раскрытых карточек.
    
- Раскрытие одной карточки не должно автоматически сворачивать другие.
    
- Не допускать наложений, обрезания содержимого, скачков прокрутки и горизонтального переполнения.
    

Полное содержимое должно сохранить описание, роли, API-статусы, настройки и проверку чата.

## 3. Наведение мышью — без мешающего окна

**Обычное наведение больше не открывает большую панель поверх списка.**

Допускается лёгкая визуальная подсветка компактной карточки.

Отдельный быстрый предпросмотр реализовать через модификатор:

- `Ctrl + наведение` — показать подробную плавающую панель.
    
- `Ctrl + клик` — закрепить эту панель.
    
- Повторное действие или `Escape` — закрыть закреплённую панель.
    
- При незакреплённом предпросмотре переход на другую карточку переключает содержимое без мерцания.
    
- При отпускании Ctrl незакреплённая панель закрывается.
    
- Начало перетаскивания всегда закрывает незакреплённый предпросмотр и не допускает его повторного появления до завершения drag.
    

Закреплённую панель нельзя случайно закрывать, пока пользователь нажимает расположенные в ней кнопки.

Для клавиатуры и устройств без Ctrl предусмотреть доступную отдельную команду «Быстрый просмотр». Обычный `Enter` / `Space` должен раскрывать карточку внутри колонки.

## 4. Умное размещение плавающего предпросмотра

Предпросмотр должен размещаться **сбоку от исходной карточки**, а не прямо поверх неё.

- Для левых колонок предпочтительно открывать справа.
    
- Для правых колонок — слева.
    
- При нехватке места автоматически выбирать более подходящую сторону.
    
- Учитывать положение относительно границ окна, закреплённой шапки и текущей прокрутки.
    
- Панель не должна выходить за экран или обрезаться.
    
- По возможности сохранять доступность остальных карточек и зон перетаскивания.
    
- При невозможности безопасного бокового размещения использовать ограниченную адаптивную альтернативу, а не накрывать рабочую колонку.
    

Проверить крайние карточки всех четырёх колонок, верх и низ страницы, изменение размеров окна, масштаб 150 %.

Не создавать несколько независимых копий полной карточки или дублирующих систем редактирования.

## 5. Клик и перетаскивание — разные действия

Реализовать надёжное различение обычного клика и движения мышью с зажатой левой кнопкой.

Предлагаемая логика:

1. `pointerdown` — зафиксировать исходную точку, но ничего не раскрывать.
    
2. Если кнопка отпущена без существенного движения, выполнить обычный клик и раскрытие.
    
3. Если мышь переместилась дальше порога примерно 6 пикселей, считать действие началом перетаскивания.
    
4. После перетаскивания отпускание кнопки **не должно** раскрывать карточку.
    
5. Если перетаскивание отменено, не создавать ложный клик и не сохранять неверный порядок.
    

Порог уточнить по реальному поведению Windows и браузера. Недопустимо, чтобы незначательное дрожание руки приводило к случайной перестановке.

Исполнитель может выбрать надёжную архитектуру событий, включая Pointer Events и существующий HTML5 drag-and-drop, но обязан исключить двойную обработку и подтвердить поведение настоящей мышью.

## 6. Перетаскивание карточек

### Перестановка внутри колонки

Карточку можно захватить мышью и перенести выше или ниже, как элементы модификаторов в Blender.

Во время перемещения показывать понятную позицию вставки: визуальный промежуток или линию между карточками.

После отпускания карточка занимает выбранную позицию, порядок сохраняется сервером и остаётся после перезапуска.

### Перетаскивание в «Избранное»

Реализовать перенос существующей карточки мышью из API, MCP / Агенты или Локальных LLM в колонку «Избранное».

Это должно **добавлять ссылку на существующую запись**, а не переносить саму модель из исходной колонки и не создавать её копию в реестре.

Внутри «Избранного» карточки также можно переставлять мышью.

При повторном переносе уже избранной записи не создавать дубликат. Удаление из избранного через существующую звёздочку сохранить.

### Общие требования к drag-and-drop

- Перетаскивание работает даже при ранее раскрытых карточках.
    
- Большая панель не перекрывает место захвата и целевые позиции.
    
- Звёздочка, «Настройки», «Проверить чат» и остальные кнопки не начинают drag.
    
- Клик не вызывает drag, drag не вызывает раскрытие.
    
- При перетаскивании доступны начальная, промежуточные и конечная позиции списка.
    
- При ошибке сохранения порядок откатывается корректно с понятным сообщением.
    
- Существующие `base_revision`, защита от конфликтов и стабильные `connection_id` сохраняются.
    
- Между основными колонками API / MCP / Локальные произвольное перемещение не разрешать; исключение — добавление ссылки в «Избранное».
    

Существующие кнопки «Выше» / «Ниже» оставить как доступный альтернативный способ сортировки.
