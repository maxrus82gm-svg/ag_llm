# Короткий физический smoke для владельца (STANDARD, без платных вызовов)

1. Открыть EVM и нажать `↗ Внешнее окно` у двух разных моделей. Проверить два отдельных системных окна, сохранность исходных карточек и отсутствие подключения/проверки API от самого открытия.
2. Обычное внешнее окно перенести на второй монитор **за системный заголовок Chrome**. Отдельно проверить `Win + Shift + ←/→`. Записать, каким способом перенос удался или что помешало; указать масштаб каждого экрана.
3. Переключить основной Web Alarm на Ultra Chat и сделать F5; внешние окна должны остаться. Закрыть и вновь открыть одно окно: модель и чат должны сохраниться.
4. В одном внешнем окне включить «Поверх всех окон», перенести PiP на второй монитор и открыть Blender поверх/под ним. Выключить режим. Проверить второе окно и возможность одновременных PiP; при отказе браузера записать текст ошибки.
5. В EVM отключить одну модель: она исчезает из выбора Ultra Chat, старый чат читается. Включить обратно. Не нажимать «Подключить GigaChat» и «Отправить тестовое сообщение» без отдельного решения о платном тесте.

Передать краткую запись: Windows/Chrome, два разрешения и масштаба, обычное окно mouse/shortcut, PiP mouse/shortcut, topmost над Blender, F5, два окна, точный текст отказа. Это будущий smoke; здесь он **не выполнен**.
