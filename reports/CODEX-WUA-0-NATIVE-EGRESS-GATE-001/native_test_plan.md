## Verdict taxonomy and automatic STOP

- **NOT_ATTEMPTED:** known caller/parser refused before network/process API;
  independent observer healthy for the scope/window and no corresponding attempt.
- **ATTEMPT_BLOCKED_BY_OS:** actual native attempt with authoritative OS denial,
  no successful peer/forward. This proves a boundary event, not client voluntarily
  staying fail-closed. Direct fallback attempt still fails the product criterion.
- **APPROVED_PROXIED_FLOW:** actual peer/route evidence matches permitted graph.
- **INCONCLUSIVE:** missing coverage/correlation/observer loss; never turn absence
  of origin traffic into absence of attempts.

Current Python `ATTEMPT_BLOCKED_BY_PYTHON_GUARD` is a different class and never an
OS verdict. An API intent row alone is not a kernel connect trace. Unexpected
scope/child/interface/policy/hash event or evidence overflow stops the run,
closes/reaps owned resources and preserves first-failure source/evidence. No
retry to real services or public-IP canary to investigate a denied path.
